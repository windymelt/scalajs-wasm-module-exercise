Scala Wasm Renderer

光線の追跡も、フラクタルも、流体の計算も、Scala 2.13 から生成した 76 KB の main.wasm が担当しています。JavaScript はマウスの動きを渡し、返ってきた画素を canvas に置くだけです。

このブラウザでは main.wasm を読み込めませんでした。Scala.js の Wasm 出力は Wasm GC と例外処理を使うため、Chrome 137、Firefox 134、Safari 26 以降で開いてください。

カメラと光源

1 画素あたりのサンプル数

サンプルを増やすと、ソフトシャドウのざらつきが減ります。

シードが同じなら、どの環境でも画素単位で同じ絵になります。

パラメータ c

c = −0.800 + 0.156i

マップはマンデルブロ集合です。塗りつぶされた集合の内側を選ぶと、ジュリア集合はひとつながりの形になります。外側を選ぶと、ばらばらの点の集まりになります。

ソルバー

格子の解像度

減らすと速くなる代わりに、流体が非圧縮でなくなり、膨らんだり縮んだりします。

渦度閉じ込め。数値計算でぼやけて消える小さな渦を補います。

光の経路

1 回にすると光源からの直接光だけになります。天井は真っ暗になり、鏡とガラスの球は黒く、壁の色も床ににじみません。

切ると、跳ね返った光線が偶然光源に当たったときしか光が届かず、同じサンプル数でもノイズがずっと多くなります。サンプルを重ねれば、どちらも同じ明るさに近づきます。

右に置くもの

グラスは厚い底のタンブラーです。ビールは屈折率 1.33 の琥珀色の液体で、上に白い泡が乗っています。

ガラスの色

ガラスの中を通る距離が長いほど、色ごとに指数関数的に吸収されます (ランベルト・ベールの法則)。縁は淡く中心は濃く、床に落ちる光も同じ色に染まります。

ガラス玉の下に集まる光の模様 (コースティクス) と、赤と青の壁の色が床ににじむ様子は、光の経路を追うだけで自然に現れます。

1 · ビルド

JS の接着コードがない .wasm

ModuleKind.WasmModule でリンクすると、出力は main.wasm だけになります。このモジュールのインポートは – 件です。

2 · 描画

1 行ずつ、1 フレーム 14 ms まで

rtSetup(...) などで条件を渡し、renderRow(y) を時間の許す限り呼びます。操作中は 160×100 の下書きを先に出します。

3 · 受け渡し

画素は px(i) で 1 つずつ

配列は境界を越えるたびにコピーされ、JS からは中身を読めません。そこで画素は整数で 1 つずつ受け取ります。25 万画素で数ミリ秒です。

流体

毎フレーム new をしない

Stam の Stable Fluids を Scala で実装しています。ホットループでは Array[Double] を使い回します。JS 以外の Wasm ランタイムでは、オブジェクトの確保が特に重いためです。

パストレーシング

三角関数なしで半球を選ぶ

拡散面では、単位円板から選んだ点を半球へ持ち上げて、コサイン重み付きの方向を作ります (Malley の方法)。sin も cos も使わずに済みます。グラスは円柱と円板の面の集まりで、面ごとに表と裏の媒質 (空気・ガラス・ビール) を決めてあるので、ガラスからビールへの屈折もそのまま計算できます。

補足

cos と log は自前実装

Math.cos や Math.log は WasmModule ではリンクできません。テイラー展開と浮動小数点のビット操作で書き直しています。
